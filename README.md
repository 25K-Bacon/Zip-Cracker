This program takes lines from a text file and tries it as a zip password.

NOTE: You need to have 7-Zip installed in "C:\Program Files\7-Zip".


"Enter Archive: ": Input your archive path, it can also be done by dragging your archive into the CMD window.

"Enter Name: ": Just input the name of the folder if it gets password guessed, it will save at the same location where the batch file is.

"Enter Wordlist: Input your text file's path, it can also be done by dragging your text file into the CMD window.
